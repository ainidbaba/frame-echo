## Automated checks

Command: `.venv/bin/python -m unittest discover -s tests -v`.

**22 tests passed.**

| Area | Checks |
| --- | --- |
| HTTP workflow | Frontend assets and capabilities, multipart upload, asynchronous completion, corrupt video/image errors, invalid settings and missing-model rejection. |
| Results and export | Synthetic fixture's nearest palette scene, ordered scores, timestamp separation, result-image delivery, ranged video delivery, CSV/JSON consistency and persisted metadata. |
| Retrieval | Colour/layout sensitivity, normalised features, transparency, temporal suppression including its exact boundary, deterministic ties and invalid vectors. |
| Video sampling | Decoded timestamps, single-frame clips, non-integral sampling intervals, no duplicated frames, bounded sampling, timestamp fallback, truncated files and time-label boundaries. |

The HTTP suite uses an isolated temporary data directory. Its missing-CLIP test deliberately checks an unconfigured instance. CLIP's real local checkpoint was checked separately below; it is not downloaded during the test suite.

## Browser workflow checks

Used the application's **Try a synthetic demo** action with a 24-second, 12-FPS, H.264 geometric palette fixture generated by `scripts/create_demo.py`. The query corresponds to the palette scene at seconds 4–8. Settings: interval 1 second, requested K = 6, minimum gap 3 seconds.

| Method | Observed functional result |
| --- | --- |
| Colour and spatial layout | 24 sampled frames; 6 results; top-ranked timestamp 5 seconds. Reference and video rendered successfully. |
| OpenCLIP image features | 24 sampled frames; 6 results; top-ranked timestamp 6 seconds. Selecting the 14-second result moved the playable source to approximately 14 seconds, then selecting the first result returned to its moment. |

Both method choices were available after setup. Results displayed the actual selected method, raw cosine scores, timestamps and an explicit **SYNTHETIC DEMO** notice. The source player reported no playback error during the checks. The CSV export endpoint was checked for agreement with result metadata in the HTTP suite.
