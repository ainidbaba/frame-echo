# Monet demonstration

The [finished demonstration](Frame-Echo-Demo-Monet.mp4) runs for 2:41 with English subtitles

## Replay the search

1. [Run Frame Echo](../project/README.md#run-frame-echo-locally) and enable CLIP image features for the recorded CLIP runs.
2. Upload the [phone video](materials/London-Phone-Video.mp4) and [reference artwork](materials/Monet-Thames-below-Westminster.jpg). The bundled phone clip preserves the video frames and omits the original audio track.
3. Set the sampling interval to 0.5 seconds, request five results and set the minimum time gap to 1.5 seconds. Choose **CLIP image features** and leave the minimum score blank. The recorded top result is at 00:05.000.
4. Set the minimum score to 0.50 to see the single result. Set it to 0.60 to see the empty state. With **Colour & layout** and a blank minimum score, the top result is at 00:08.500. [Recorded search and playback values](materials/recorded-searches.json).
