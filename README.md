# Frame Echo

Frame Echo takes an artwork as a visual reference and finds potentially similar frames in a video. It ranks candidate frames and lets viewers jump to their source timestamps.

# Generative AI Use Statement

Statement on the Use of Generative Artificial Intelligence
During the development of Frame Echo, generative AI tools—including ChatGPT, Claude and Codex—were utilised to assist with brainstorming, programming, debugging, documentation and language editing.

AI-generated suggestions were reviewed and refined throughout the development process. The authors remain solely responsible for the project’s research direction, creative decisions, website design, user testing and the interpretation of results.

Artificial intelligence is used as a supplementary tool for independent research, critical thinking or creative practice, rather than as a substitute.
